# Day-two operations

## Daily / weekly
- Check OPNsense firewall alerts, VPN access and unexpected denied flows.
- Review Proxmox and Nutanix CE capacity and hardware alarms.
- Check Kubernetes nodes, pods, restarts and persistent volume status.
- Review ZFS pool health and disk SMART status.
- Verify backup jobs complete and copies exist off the primary system.

## Monthly / quarterly
- Test representative restore of VM and NAS data.
- Patch firmware, hypervisors, firewall and applications in a planned window.
- Review administrative accounts, MFA and SSH keys.
- Run ZFS scrubs and record error trends.
- Review capacity, certificates, DNS and alerting thresholds.

## Change control
Record planned change, expected impact, backup, test plan, rollback steps and validation evidence. Never perform risky bridge/firewall changes without alternate management access.
